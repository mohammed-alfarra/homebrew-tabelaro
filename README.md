# Homebrew tap for Tabelaro

[Tabelaro](https://tabelaro.com) is a free database client for macOS: PostgreSQL, MySQL/MariaDB and SQLite, with no account and no telemetry.

```sh
brew install --cask mohammed-alfarra/tabelaro/tabelaro
```

Or tap it first:

```sh
brew tap mohammed-alfarra/tabelaro
brew install --cask tabelaro
```

To update, run `brew reinstall --cask tabelaro`, which downloads the latest build.

Tabelaro is not signed or notarized, so this cask removes the macOS quarantine flag after installing. Questions: feedback@tabelaro.com
